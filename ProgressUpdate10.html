UX Rules ใหม่ในรอบนี้

มาตรฐานพฤติกรรมที่ Apply ทั่วระบบ
🔍 Show More Popup Behavior
เมื่อ dropdown ของ AutocompleteCellEditor มีรายการเยอะ ผู้ใช้กด "แสดงเพิ่มเติม..." เพื่อเปิด popup ค้นหาแบบละเอียด
  • Product Popup: multi-select (checkbox + ปุ่มตกลง)
  • UOM Popup: single-select (checkbox disabled, ใช้ row click)
  • คอลัมน์ "หน่วย" ใน Product Popup ดึงจาก batch m_uom
  • Insert หลายแถว → default qty=1 (ใบเบิก/ใบส่ง ฯลฯ)
🧩 Multi-Select Row Empty Replace
เมื่อ focused row เป็น row ว่าง ให้แทนที่ด้วยสินค้าตัวแรก แทน append ต่อท้ายเสมอ
  • เช็ค focused row ก่อน insert
  • ถ้า row ว่าง → แทนที่ด้วยสินค้าตัวแรก
  • ถ้ามีข้อมูลแล้ว → append ต่อท้าย
🪟 Maximize / Restore Pattern
ทุก dialog ที่ใหญ่ (3-zone + wizard) มีปุ่ม Maximize/Restore ใน topbar
  • Normal: popup 95vw, 3 columns
  • Full Screen: 5-6 columns/row (responsive)
  • Save/Confirm ใน Full Screen → ไม่ปิด dialog, reload data
  • Back button มุมซ้ายบน (เฉพาะ fullscreen)
⌨️ Unsaved Changes Guard (มาตรฐาน)
กดปิด/Escape ถ้ายังไม่บันทึก → แสดง warning dialog ทุกหน้า
  • isDirty getter ครอบคลุม new + existing
  • attemptClose() เป็น single source of truth
  • Escape key bind ผ่าน dirty check
  • ปุ่ม "ปิด" ใน footer → attemptClose()
  • [closable]="false" ปิด default close ของ p-dialog
⭐ Required Field Indicator
เครื่องหมาย * สีแดงบน label ของฟิลด์ที่บังคับ (เริ่มที่ Sale Order — ลูกค้า)
  • วาง * แดงไว้หลัง label
  • ใช้กับฟิลด์ที่ทำให้ Save/Confirm ไม่ผ่าน
  • ต่อยอด apply ทุกหน้าได้
🔄 Reload After Save in Full Screen
กด Save/Confirm ใน Full Screen → ไม่ปิด dialog, reload data ทับ form (สอดคล้องกับ Section 34 Global Save)
  • Full Screen — โหมดทำงานต่อเนื่อง
  • Normal Save behavior ยังคงเดิม
  • Sync กับเอกสารใหม่ที่เพิ่งสร้างทันที
